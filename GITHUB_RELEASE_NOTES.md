# AtlaswebX v1.0.0 🚀

First public release of AtlaswebX - an AI-powered web browser built with Electron!

## 📦 Download

**Windows**: `AtlaswebX-Setup-1.0.0.exe` (Installer)

**Requirements**: Windows 10/11 (64-bit), 4GB RAM, 200MB disk space

## ✨ Features

### 🌐 Web Browser
- ✅ Tabbed browsing with smooth navigation
- ✅ Multiple search engines (Google, Bing, DuckDuckGo, Brave)
- ✅ Custom user agent (Chrome 142)
- ✅ Right-click context menu
- ✅ Back, forward, reload, home controls

### 🤖 AI Assistant
- ✅ GPT-4o-mini powered chat
- ✅ Page content analysis
- ✅ Conversation history
- ✅ Element selection tool
- ✅ Clear conversation button

### 🎨 Customization
- ✅ 6 gradient themes
- ✅ 6 high-quality wallpapers
- ✅ Custom wallpaper upload
- ✅ Auto-save settings
- ✅ Multi-language support (EN, FR, ES, DE, AR)

### 🔐 Privacy
- ✅ Local storage only
- ✅ No tracking
- ✅ Secure API key storage
- ✅ Open source

## 🚀 Quick Start

1. Download `AtlaswebX-Setup-1.0.0.exe`
2. Run the installer
3. Launch AtlaswebX
4. (Optional) Add OpenAI API key in Settings for AI features

## 🔑 AI Setup (Optional)

To use the AI Assistant:
1. Get an API key from https://platform.openai.com/api-keys
2. Open Settings → AI Settings
3. Paste your OpenAI API key
4. Save and start chatting!

- First AI message may take a few seconds (API initialization)
- Custom wallpaper upload limited to 10MB
- Settings open in separate window (by design)
