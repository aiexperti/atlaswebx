# 🚀 Quick Start - AI Live Website Editing

## Get Started in 3 Steps

### 1. Load Any Website
Open the Electron app and navigate to any website. The AI monitoring system will automatically inject and start capturing data.

### 2. Open AI Sidebar
Click the AI button or press `Ctrl/Cmd + K` to open the AI assistant sidebar.

### 3. Start Editing
Type natural language commands to edit the page:

```
"Make the background dark"
"Hide all advertisements"
"Create a minimal layout"
"Extract all product data"
```

## What's Happening Behind the Scenes?

When you load a page:

1. ✅ **Scraper injected** - Monitors all activity
2. ✅ **Page scrolled** - Triggers lazy loading
3. ✅ **Data captured** - Network, storage, state
4. ✅ **Screenshot taken** - Visual context
5. ✅ **Analysis complete** - Ready for AI

When you ask AI to edit:

1. 🤖 **AI receives context** - Complete page data
2. 🎯 **AI generates actions** - Precise modifications
3. ⚡ **Actions executed** - Changes applied instantly
4. 💾 **Optional save** - Save as rule for future visits

## Features You Get

### Automatic Monitoring
- 📡 All network requests (XHR, Fetch, WebSocket)
- 💾 Browser storage (localStorage, cookies, IndexedDB)
- 🎯 Framework detection (React, Vue, Angular)
- 📊 JSON data from APIs
- 🖼️ All images and media

### Intelligent Editing
- 🎨 Style modifications
- 🔧 Element manipulation
- 🏗️ Complete redesigns
- 📊 Data extraction
- 🔍 Content filtering

### Persistent Rules
- 💾 Save edits as rules
- 🔄 Auto-apply on future visits
- ⚡ Toggle on/off per domain
- 🗑️ Clear rules anytime

## Tips for Best Results

### ✅ Do This
- Be specific: "Make the text 18px"
- Describe the goal: "Create a dark theme"
- Reference visible elements: "Hide the left sidebar"
- Use Advanced Mode for complex changes

### ❌ Avoid This
- Vague requests: "Make it better"
- Without context: "Change the CSS"
- Impossible requests: "Add features that don't exist"

## Advanced Features

### Enable Advanced Mode
1. Open AI settings
2. Toggle "Advanced Mode"
3. Get GPT-5 powered editing
4. Better for complete redesigns

### Save Rules
1. Make successful edits
2. Click "Save as Rule"
3. Name your rule
4. Auto-applies on future visits

- Toggle rules: Click indicator button

## What Can You Edit?

### ✅ Supported
- Static websites
- Dynamic SPAs (React, Vue, Angular)
- E-commerce sites
- News sites
- Social media
- Video platforms
- Web applications

### ⚠️ Limitations
- Some sites block script injection
- Shadow DOM may need special handling
- Heavy security sites may restrict access

## Privacy & Security

### Your Data
- ✅ Stays local on your computer
- ✅ Never sent to external servers (except AI API)
- ✅ Cleared on page navigation
- ✅ No tracking or analytics

### Best Practices
- Don't use on banking/sensitive sites
- Review actions before saving as rules
- Clear rules containing sensitive data
- Use incognito for testing
