## 🎉 Welcome to AtlaswebX!

AtlaswebX is an AI-powered web browser built with Electron, featuring an integrated GPT-4o-mini assistant, custom wallpapers, and a modern, intuitive interface.

## 📦 Download

### Windows
- **AtlaswebX-Setup-1.0.0.exe** - Windows Installer (Recommended)
- Double-click to install and run

### System Requirements
- **OS**: Windows 10/11 (64-bit)
- **RAM**: 4GB minimum, 8GB recommended
- **Disk Space**: 200MB
- **Internet**: Required for browsing and AI features

- **Tabbed Browsing** - Multiple tabs with smooth navigation
- **Address Bar** - Type URLs or search directly

## 🚀 Getting Started

### Installation

1. **Download** the installer: `AtlaswebX-Setup-1.0.0.exe`
2. **Run** the installer
3. **Follow** the installation wizard
4. **Launch** AtlaswebX from your desktop or Start menu

### First Launch

1. **Welcome Screen** - You'll see the home screen with apps
2. **Browse the Web** - Click the address bar and type a URL
3. **Open Settings** - Click the gear icon to customize
4. **Set Up AI** (Optional):
   - Click Settings → AI Settings
   - Enter your OpenAI API key
   - Save and start chatting!

### Getting an OpenAI API Key

1. Go to https://platform.openai.com/api-keys
2. Sign up or log in
3. Click "Create new secret key"
4. Copy the key
5. Paste it in AtlaswebX Settings → AI Settings

## 🔧 Technical Details

### Built With
- **Electron** - Cross-platform desktop framework
- **Node.js** - JavaScript runtime
- **OpenAI GPT-4o-mini** - AI language model
- **Custom UI** - Modern, responsive design

### Architecture
- **Main Process** - Electron main window and IPC
- **Renderer Process** - UI and user interactions
- **BrowserView** - Efficient tab rendering
- **IPC Communication** - Seamless process communication

### File Size
- **Installer**: ~150MB
- **Installed**: ~200MB

## 🐛 Known Issues

### Minor Issues
- First AI message may take a few seconds (API initialization)
- Custom wallpaper upload limited to 10MB
- Settings window opens in separate window (by design)

### Workarounds
- **AI Slow?** - First message initializes the connection, subsequent messages are faster
- **Large Image?** - Resize images before uploading as wallpaper
- **Settings?** - Close settings window when done to return to browser
