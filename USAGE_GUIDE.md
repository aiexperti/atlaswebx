# Lenoir AI Browser - Usage Guide

## Navigation Overview

### Home Screen
- **Initial View**: When you launch the app, you'll see the home screen with app shortcuts
- **Clock Display**: Shows current time (updates every second)
- **App Grid**: Click any app icon to open it in a new tab

### Tab Management

#### Opening Tabs
1. **From Home Screen**: Click any app shortcut
2. **From URL Bar**: Type a URL or search term and press Enter
3. **New Tab Button**: Click the `+` button in the tab bar

#### Switching Between Tabs
- **Click on Tab**: Click any tab in the tab bar to switch to it
- **Tab Bar**: Always visible when you have open tabs
- The active tab is highlighted with a border

#### Closing Tabs
- **Close Button**: Hover over a tab and click the `×` button
- **Last Tab**: When you close the last tab, you'll return to the home screen

### Returning to Home Screen

#### Method 1: Home Button
- Click the **Home icon** (house icon) in the navigation bar
- This shows the home screen while keeping your tabs open
- You can click any tab to return to browsing

#### Method 2: Close All Tabs
- Close all tabs one by one
- The home screen will appear automatically

### Navigation Controls

- **Back Button** ← : Go back in history
- **Forward Button** → : Go forward in history  
- **Reload Button** ⟳ : Refresh current page
- **Home Button** 🏠 : Return to home screen (highlighted button)
- **AI Toggle** 💬 : Open/close AI assistant sidebar

### URL Bar
- **Enter URL**: Type full URL (e.g., `https://google.com`)
- **Auto-Protocol**: Type domain only (e.g., `google.com`) - automatically adds `https://`
- **Search**: Type search terms - automatically searches on Google
- **Press Enter**: Navigate to URL or search

### AI Assistant Sidebar

#### Opening/Closing
- Click the **chat icon** in the navigation bar
- Click the **X** button in the sidebar header
- Sidebar slides in from the right

#### Features
- **Suggestions**: Quick action buttons at the top
- **Chat Interface**: Ask questions about the current page
- **Message Input**: Type and press Enter or click send button

## Tips

1. **Multiple Tabs**: You can have multiple tabs open and switch between them easily
2. **Home + Tabs**: The home screen and tabs can coexist - use the home button to access shortcuts while keeping tabs open
3. **Smart URL Bar**: No need to type `https://` - just type the domain
4. **Tab Visibility**: Tabs remain visible in the tab bar even when viewing the home screen
5. **Quick Access**: Use app shortcuts on home screen for frequently visited sites

## Troubleshooting

### Can't see tabs
- Make sure you've opened at least one page by clicking an app shortcut or using the URL bar

### Can't return to home screen
- Click the home button (house icon) in the navigation bar
- It's highlighted with a darker background for easy identification

### Tab not switching
- Click directly on the tab (not the close button)
- The active tab will have a visible border

### Browser view not showing
- Click on a tab to activate it
- If home screen is showing, click any tab to return to browsing
