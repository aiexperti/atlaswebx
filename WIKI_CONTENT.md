# AtlaswebX Wiki Content

This file contains all the wiki pages ready to be uploaded to GitHub Wiki.

## 📝 How to Create the Wiki

### Step 1: Enable Wiki on GitHub

1. Go to https://github.com/aiexperti/atlaswebx/settings
2. Scroll to "Features"
3. Check ✅ "Wikis"
4. Click "Save changes"

### Step 2: Create Wiki Pages

1. Go to https://github.com/aiexperti/atlaswebx/wiki
2. Click "Create the first page"
3. Copy content from the files in `/wiki/` folder
4. Create each page listed below

## 🚀 Quick Setup Instructions

### Option 1: Manual (Recommended for First Time)

1. Enable Wiki on GitHub (see Step 1 above)
2. Go to Wiki page
3. Click "Create the first page"
4. Title: "Home"
5. Copy content from `wiki/Home.md`
6. Click "Save Page"
7. Repeat for each page

### Option 2: Git Clone (Advanced)

```bash
# Clone wiki repository
git clone https://github.com/aiexperti/atlaswebx.wiki.git

# Copy wiki files
cp wiki/*.md atlaswebx.wiki/

# Push to wiki
cd atlaswebx.wiki
git add .
git commit -m "Initial wiki content"
git push origin master
```
