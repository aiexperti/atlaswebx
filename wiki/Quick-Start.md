# Quick Start Guide

Get up and running with AtlaswebX in 5 minutes!

## 🚀 5-Minute Setup

### 1. Install AtlaswebX (2 minutes)

1. Download from [Releases](https://github.com/aiexperti/atlaswebx/releases/latest)
2. Run installer
3. Click through wizard
4. Launch AtlaswebX

See [Installation Guide](Installation-Guide) for details.

### 2. Browse the Web (1 minute)

1. Click the **address bar** at top
2. Type a URL or search term
3. Press Enter
4. Start browsing!

**Try it**:
- `google.com`
- `github.com`
- `what is electron`

### 3. Open Multiple Tabs (1 minute)

1. Click **"+"** button next to tabs
2. Or press `Ctrl+T`
3. Each tab is independent
4. Switch between tabs by clicking

### 4. Use AI Assistant (Optional - 1 minute)

1. Click **AI icon** in sidebar
2. Type a question
3. Get instant answers
4. Ask about current page

**Note**: Requires OpenAI API key. See [API Key Setup](API-Key-Setup).

## 🎯 Essential Features

### Address Bar

**Type to**:
- Enter URLs: `example.com`
- Search: `weather today`
- Quick access: Just start typing

**Shortcuts**:
- `Ctrl+L` - Focus address bar
- `Enter` - Navigate
- `Alt+Enter` - Open in new tab

### Navigation

**Controls**:
- ← **Back** - Previous page
- → **Forward** - Next page
- ⟳ **Reload** - Refresh page
- 🏠 **Home** - Go to homepage

**Shortcuts**:
- `Alt+←` - Back
- `Alt+→` - Forward
- `Ctrl+R` or `F5` - Reload
- `Alt+Home` - Home

### Tabs

**Actions**:
- `Ctrl+T` - New tab
- `Ctrl+W` - Close tab
- `Ctrl+Tab` - Next tab
- `Ctrl+Shift+Tab` - Previous tab
- `Ctrl+1-8` - Go to tab 1-8
- `Ctrl+9` - Go to last tab

### Search Engines

**Default**: Google

**Change**:
1. Open Settings
2. Go to Search Engine
3. Choose: Google, Bing, DuckDuckGo, or Brave

### Context Menu

**Right-click anywhere** for:
- Copy, Cut, Paste
- Open Link in New Tab
- Save Image
- Copy Page URL
- Reload

## 🎨 Customize Your Browser

### Change Wallpaper

1. Click **Settings** (gear icon)
2. Go to **Appearance**
3. Choose a wallpaper:
   - 6 gradient themes
   - 6 photo wallpapers
   - Upload custom image

### Set Homepage

1. Open Settings
2. Enter homepage URL
3. Saves automatically

### Change Language

1. Open Settings
2. Select Language
3. Choose from:
   - English
   - Français
   - Español
   - Deutsch
   - العربية

## 🆘 Common Questions

### How do I close a tab?

- Click **X** on tab
- Or press `Ctrl+W`
- Or middle-click tab

### How do I open a link in new tab?

- Right-click link → "Open Link in New Tab"
- Or `Ctrl+Click` link
- Or middle-click link

### Where are my settings saved?

Settings are stored locally in:
```
C:\Users\[YourName]\AppData\Roaming\atlaswebx\
```

### Can I use without AI?

**Yes!** AI is completely optional. AtlaswebX works as a full browser without any API key.

### Is my data private?

**Yes!** Everything is stored locally. No data is sent to our servers (we don't have any!).
